# Agent Instructions

You are an AI agent building a GTA 6 meme generator for the make.fun bounty "Post a GTA 6 meme on X".

## Task
Create a TypeScript program that generates a GTA 6 style meme image with:
- GTA 6 branding (Vice City aesthetic, neon pink/cyan colors)
- "13 YEARS LATER" reference
- make.fun ghost mascot
- @makefunai tag
- Text about waiting for GTA 6

## Requirements
- Use Node.js 22+ with canvas library
- Output 1080x1080 PNG suitable for X/Twitter
- Include make.fun branding
- Save to output/meme.png

## Tech Stack
- TypeScript
- canvas (node-canvas)
- Node.js 22+

## Output
The program should generate a meme image and save it to `output/meme.png`.
